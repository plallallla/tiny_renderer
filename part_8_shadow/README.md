# Shadow Map

#### 0.why

为提高渲染真实感，我们可以尝试渲染出阴影，也即光线无法照射到的地方，适当降低其亮度。在之前的光照模型中，Phong模型更关注于局部的光线渲染，而在全局尺度下、他无法考虑其空间中的遮挡关系，从而构建出全局的阴影效果。因此我们需要一种新的方法来实现全局的光照。

#### 1.what

我们可以认为，某部分之所以产生阴影，是因为光线无法照射到它，也就是光源发出射线后，被物体遮挡住。如果空间中有一点P，他如果被光源遮挡，那么他与光源Light之间一定存在一个不透明物体Q，使得他与光源之间无法建立一条连续光路。此时，可以判定Light到Q的距离一定小于Light到P的距离。这种比较同一视觉距离的方法可以类比之前渲染时使用的Z-buffer，也即为每个片元构建一个深度缓冲，渲染过程中不断更新每个片元的深度值，渲染完成后，Z-buffer中缓存的每个值一定是当前片元的最小深度值。

```c++
if (z <= zbuffer[current_fragment]) continue;// discard fragments that are too deep w.r.t the z-buffer
zbuffer[current_fragment] = z; // update the z-buffer
```

#### 2.how

实际渲染时，我们需要首先将整个场景切换到光源视角，生成光源视角下的“Z-buffer”，他是一个基于片元进行记录的缓存，记录有每个片元到光源的最短距离，也就是被照亮的部分。然后再实际渲染过程中，我们对片元着色器中的片元再进行一次变换，将这个片元从摄像机视角转换到光源视角，计算这个片元与光源的距离，如果距离大于照亮的部分，说明他被阻挡，反之被照亮。

##### 2.1 如何从光源视角渲染场景

从光源视角出发渲染，我们只需要在正常渲染时将相机的pos切换成光源的pos即可，实际操作时，我们修改生成ModelView的LookAt函数的传入参数，将原本的Camera替换成Light即可。在Light视角下渲染，不需要关心具体的片元结果，我们只关心深度值。

##### 2.2 如何计算片元到光源的距离

由于最终阴影是在片元着色中进行的，因此我们都考虑screen坐标，问题就转为已知一个camera视角下的screen坐标，求他在light视角渲染下与light的距离。

首先，模型中的一点P转为screen坐标如下
$$
screen=M_{viewport}M_{prospective}M_{Modeview}P
$$
记整个转换过程为一个整体矩阵M，那么
$$
screen=MP
$$
记光源视角下的转换矩阵为N，相机视角下的为M
$$
fragment_{light}=NP\\
fragment_{camera}=MP
$$
可知对应的转换过程如下
$$
fragment_{light}=NM^{-1}fragment_{camera}
$$
